REPTRACK PRO V3

1. En Supabase > SQL Editor, ejecuta COMPLETO el archivo supabase_schema.sql de esta versión.
2. Debe aparecer: Success. No rows returned.
3. Abre index.html.
4. Inicia sesión con tu cuenta habitual.
5. Pulsa ☁️.
6. En TU PERFIL EN EL GRUPO podrás cambiar el nombre que aparece como persona. Si ahora aparece "Gimnasio", pon "Jorge" y pulsa Guardar nombre.
7. El nombre del grupo se muestra separado arriba. El código de invitación pertenece al grupo.
8. Desde PERSONAS DEL GRUPO, el creador puede eliminar al otro miembro.
9. Desde el selector de personas, cada perfil local también tiene botón 🗑️ para eliminarlo del dispositivo (si es un compañero sincronizado, se elimina del grupo mediante el control del creador).

IMPORTANTE: no crees otro proyecto de Supabase y no uses la Secret Key. Mantén la Publishable Key.
